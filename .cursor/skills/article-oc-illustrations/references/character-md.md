# character.md テンプレ

記事スラッグの配図フォルダに `character.md` として保存する。短く保つ。

```markdown
# キャラ: {名前}

## 基本
- 名前:
- 一言（役割・性格）:
- シルエット（何に見えるか）:
- 体の色・線:
- アクセント色（0–2色）:
- 目・手足の特徴:

## 性格
- やる感じ:
- やらないこと:（売萌・マスコット化・途中で別キャラ化 など）

## 動作
- 得意な動作:（運ぶ / 押す / 塞ぐ / 押印 / 濾す など）
- この記事でやらせたい動作:

## 禁止
- 小黒（黒豆）化しない
- 記事途中でデザイン変更しない
- 注記にキャラ名を毎図書かない（必要なときだけ）

## 参照画像（任意）
- キャラシート:
- スタイル固定用の成功図:
```

セッションをまたぐときは、このファイルを読めば同じキャラで再開できる。
