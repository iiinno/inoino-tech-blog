# オリキャラ発明

記事ごとに1体。レギュラー名簿から選ぶスキルではない。

## 手順

1. 記事の核心を一文にする
2. それを **物理的な道具・記号・状態** に落とす（抽象のまま擬人化しない）
3. シルエットが一目で分かる形にする（黒豆・汎用マスコット禁止）
4. 性格は短く。動作は記事の認知アンカーに奉仕させる
5. `character.md` に書いてから配図する

## 視点のばらし方（必要なら）

毎回同じ「文房具」にしない。どれか retro を変える:

- 道具（クリップ、メジャー…）
- 記号（Σ、π…）
- 状態（影、余白、墨…）
- UI（キャレット…）
- 動作そのもの（濾す、押す、塞ぐ…）

## 品質

- かわいい売萌より、死んだ目の作業員
- 色は抑える（線は黒、アクセントは少なく）
- 1記事1シルエット。バリエーションはポーズと小物だけ
