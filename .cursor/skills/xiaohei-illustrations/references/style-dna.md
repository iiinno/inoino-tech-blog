# スタイル DNA

## 一言

純白・極簡・手描き・余白・抑制・怪誕・プロダクトスケッチ感・**日本語手書き注記**・構造は分かるが説明書ではない。

AI・プロダクト・開発ツールを長く触ってる人が、白紙にサッと描いた説明ラフ。

## 必須

- 16:9 横
- 純白背景（米色・紙テクスチャ・グラデ・影・ノイズ禁止）
- 黒い手描き線（細い・わずかに揺れ・ベクタ感なし）
- 余白多め（主体 40–60%、空白 35%以上）
- 日本語手書き注記は少なく短く（最大 5–8、各 2–8 字）
- 1枚1メッセージ
- 図上に構造タイプ名を書かない

## 色

- 黒: 線・小黒・主構造・主文字
- 赤: 問題・感情ピーク・結果・警告
- 橙: 主フロー・矢印・移動
- 青: 補足・内面・システム状態・AI側の注記（必須ではない）

少なく。足りないくらいが正解。

## 禁止

商業イラスト / PPT情報図 / 正式フロー / 课件 / かわいいマスコット / 子ども向け / 複雑アーキ図 / フラット精緻イラスト / テックUI / 実スクショ / 複雑背景 / 左上の「フローチャート」系タイトル
