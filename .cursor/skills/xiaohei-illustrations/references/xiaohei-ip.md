# 小黒 IP

## 定義

黒塗り・白目・細い足・無表情の小さな存在。マスコットではなく、**システムの中で本気で変な仕事をしている作業員**。

デフォルトで毎図に登場。いのまさ向けでも同じ見た目を維持する（ローカライズは注記言語だけ）。

## 外形

- 黒の実体（豆・筒・箱・影・穴・機械の中の黒塊でも可）
- 白い点目
- 細い足（腕も細い）
- 輪郭は少しいびつ（手描き）
- 表情は空・冷静・真剣

## 性格

真剣だがやることが少し荒诞。冷たいユーモア。売萌しない。

## 役割

核心動作を担う: 運ぶ / 線を引く / 断点に嵌る / レバー操作 / 漏斗になる / 切る / 押印 / 道を引く / 警告牌 / 橋を架ける / 仕分け など。

## 判定

小黒を消してもメタファーが成立するなら、飾りすぎ → プロンプトを書き直し、動作主体にする。
